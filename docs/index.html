Why host? Your server = low ping for you and your friends.
Setup (5 min, one time):
1. Install Node.js
2. git clone https://github.com/gravityst/snake.io.git
3. cd snake.io && npm install
Run each time you play:
SUBDOMAIN=yourname npm run host
(Windows: set SUBDOMAIN=yourname && npm run host)

Your URL: https://snakeio-yourname.loca.lt
Then: Paste the URL above → Save. Saved forever — next time you host, game auto-switches.
